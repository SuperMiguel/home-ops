# Grafana MCP secrets (1Password)

Create Homelab vault item **`grafana-mcp-secrets`**:

| Field | Value |
| --- | --- |
| `GRAFANA_SERVICE_ACCOUNT_TOKEN` | Grafana SA token (Viewer) for OpenClaw |

In Grafana: **Administration → Service accounts → Add** → role **Viewer** → **Add token**.

Remote refs: `grafana-mcp-secrets/GRAFANA_SERVICE_ACCOUNT_TOKEN`
